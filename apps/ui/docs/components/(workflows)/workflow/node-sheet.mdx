<RegistryInstall name="workflow-node-sheet" />

`WorkflowNodeSheet` is a shadcn `Sheet` for the selected step. Settings lists the step's fields and ports and, for AI steps, a model picker. Run shows the step's log lines and Output shows its sample result once it completes. Pass `onDelete` to add a Delete step button.
