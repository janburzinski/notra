<Component path="workflow/examples/workflow-timer" />

<RegistryInstall name="workflow-timer" />

`WorkflowTimer` formats milliseconds as `1.4s` or `12m 34s` with tabular numbers, so it doesn't jitter while it ticks. Set `running` to add a pulsing dot. Nodes, the run toolbar and the node sheet all use it.
