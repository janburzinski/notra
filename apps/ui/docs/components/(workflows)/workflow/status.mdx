`WorkflowStatusBadge` and `WorkflowStatusIndicator` cover every step status: idle, queued, running, waiting for approval, completed, failed and skipped. `WorkflowDeterminismBadge` tells deterministic tasks apart from AI steps, whose output can change between runs.
