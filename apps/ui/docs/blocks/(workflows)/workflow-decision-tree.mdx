<Component path="workflow/examples/workflow-decision-tree" />

When a page loses AI visibility, Gemini diagnoses why and a decision routes it to the matching fix: Claude rewrites stale sections, a task generates schema, a GitHub PR unblocks the crawler or GPT writes a comparison page. A merge waits for the fix and Webflow publishes it. Pick a diagnosis in the toolbar and press Run to watch the other branches get skipped.
