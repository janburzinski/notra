Notra is now available as a plugin in ChatGPT. You can find it on [Notra's plugin page in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6ad054bf08248191a320ed1334e3ffde) and connect it to your ChatGPT account without copying a server URL or creating an API key.

## What changed [#what-changed]

You could already use Notra in ChatGPT by adding `https://mcp.usenotra.com/mcp` as a custom connector or by going through our [Composio integration](/blog/notra-is-now-available-on-composio), but both options asked you to set something up by hand before you could ask your first question. Notra now has its own plugin in ChatGPT, so your team can find it and add it the same way they add any other plugin.

## How to connect [#how-to-connect]

Open [Notra's plugin page](https://chatgpt.com/plugins/plugin_asdk_app_6ad054bf08248191a320ed1334e3ffde) and click Install plugin. ChatGPT sends you to Notra to sign in, where you pick the organization you want to use and an access level of Read only, Write only or Full access. ChatGPT stores the session and refreshes it in the background, so you only sign in once.

If you use Claude as well, our [verified Claude connector](/blog/notra-is-now-a-verified-claude-connector) connects to the same server and gives you the same tools.

## What you can do with it [#what-you-can-do-with-it]

The plugin has the same tools as our [MCP server](https://www.usenotra.com/docs/devtools/mcp), which covers GEO, AEO and content. Here are a few prompts to start with:

- "Run a GEO scan for our tracked prompts and tell me where we dropped since last week."
- "Which competitors show up in AI answers for prompts where we don't?"
- "Find our biggest content gaps and draft a blog post for the first one in our brand voice."
- "How much traffic did AI crawlers and agents send to our docs this month?"

In one conversation, ChatGPT can read your visibility data, compare it against competitors, plan a content brief and write the draft. ChatGPT saves each draft as a post in Notra, where you review and publish it from the dashboard.

Some tools use credits or can't be undone, such as running scans, approving briefs and deleting data, so ask ChatGPT to show you what it plans to do and confirm before it runs them.

## What's next [#whats-next]

We'll add new tools to the plugin as we ship them in Notra. If a tool is missing or doesn't work the way you expect, ask ChatGPT to send us feedback through the plugin or contact us directly, and we'll read every report.
