**Last updated: November 6, 2026**

A sub-processor is a third party that Notra, Inc. engages to process personal data on behalf of our customers, for example to host the Service, store data or run AI models. This page is Annex III of our [Data Processing Agreement](/dpa) and lists every sub-processor that can receive Customer Personal Data, what it does for us, which data it handles and where it is based.

We tell customers about a new or replacement sub-processor at least 14 days before it starts processing Customer Personal Data. We announce changes by updating this page. To also get each notice by email, write to support@usenotra.com and we will add you to the notification list. You can object to a change as described in section 10 of the DPA by emailing support@usenotra.com.

Notra, Inc. is established in the United States, so transfers of personal data from the EU, the UK and Switzerland to Notra are covered by the Standard Contractual Clauses in our DPA. Most sub-processors below are also based in the United States.

## AI Model Providers

Notra sends prompts and context to AI models to answer chat messages, run agents, generate content, run GEO visibility scans, classify feedback and evaluate results. Requests go through an AI gateway, which chooses the inference provider that serves each request and can fail over between providers for the same model. Some GEO engines call a provider directly. Requests through Vercel AI Gateway and OpenRouter are sent with prompt training disallowed. Neon AI Gateway does not offer that setting, so requests through it are covered by the API terms of Neon and the model provider. Workspaces with the zero data retention ("ZDR") add-on only use providers that keep no prompts.
