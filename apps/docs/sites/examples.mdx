Every example is a complete site folder in [`sites`](https://github.com/usenotra/sites-examples/tree/main/sites) of the [Notra examples repository](https://github.com/usenotra/sites-examples), with its own `blog.json`, posts, changelog and a README that lists what it shows. Examples served under a path also have a small app or config for the main website in [`hosts`](https://github.com/usenotra/sites-examples/tree/main/hosts).

To start from one, copy its folder into your repository and create a site from it under **Sites → New site**. If the folder isn't at the root of the repository, turn on **Site is in a subdirectory** and enter its path.

## Design and features

For the unmodified default theme, use [`sites/default`](https://github.com/usenotra/sites-examples/tree/main/sites/default). It includes sample blog posts and release notes without custom styles or components. Deploy it with **Site is in a subdirectory** set to `sites/default`, the blog path set to `/blog` and the changelog path set to `/changelog`.
