An AI referral is a person who clicked a link in an AI answer and landed on your site. Notra recognizes them by the referrer host:

| Engine | Hosts |
| --- | --- |
| ChatGPT | chatgpt.com, chat.openai.com |
| Perplexity | perplexity.ai |
| Gemini | gemini.google.com, bard.google.com |
| Claude | claude.ai |
| Microsoft Copilot | copilot.microsoft.com, bing.com/chat |
| You.com | you.com |
| DeepSeek | chat.deepseek.com |
| Mistral | chat.mistral.ai |
| Grok | grok.com, x.ai |
| Qwen | chat.qwen.ai |
| Meta AI | meta.ai |

Subdomains of these hosts also count, and the server tracker and log drains go by the referrer alone. In [Web analytics](/analytics/web-analytics), a page view also counts as coming from AI when its link carries one of these hosts as `utm_source`, such as `utm_source=chatgpt.com`, which ChatGPT's apps add because they send no referrer.

## Conversions

Add **Conversion paths** in [Brand and domains](/geo/brand-and-domains), for example `/signup` or `/pricing`, up to 20 of them.

A conversion is an AI referral that lands on one of those paths. Paths match by prefix, so `/pricing` also counts `/pricing/teams`, while `/` only matches the home page.

Conversions show up as the **Conversions** stage in the hero of the [AI analytics](/analytics/overview) page, for the selected date range.

<Visibility for="agents">

`GET /v1/projects/{projectId}/geo/traffic/overview` returns `totals.conversions`, which is `null` when the project has no conversion paths.

</Visibility>

## Limits

- Notra only counts the page the referral landed on, so a visitor who lands on a blog post and signs up later is not a conversion.
- Notra doesn't count visits from apps that strip the referrer header or from AI engines missing from the table as referrals.
