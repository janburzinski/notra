Every enabled engine answers every enabled prompt on each scan, and you pick the engines under **Settings > Models**.

## Default engines

New projects start with ChatGPT, Google AI Overviews and Gemini. Brands that sell to consumers, such as products people buy, book or visit, get Google AI Overviews on top of ChatGPT and Gemini, which Notra decides from your website during onboarding.

## Assistants

Every plan can track every assistant below, and each appears once in the picker.

Notra captures ChatGPT, Gemini, Copilot and Google answers from the apps themselves rather than from model APIs, so you see the same answer a buyer gets when they open the app. These engines save the sources they cited. See [How scans work](/geo/how-scans-work) and [Citations](/geo/metrics/citations).

| Assistant | How Notra collects it |
| --- | --- |
| ChatGPT | The ChatGPT app with web search |
| Gemini | The Gemini app |
| Microsoft Copilot | The Copilot app |
| Google AI Overviews | Google search results |
| Google AI Mode | Google AI Mode results |

Claude, Grok, Kimi, GLM and DeepSeek answer through their model APIs without web search, from what each model learned in training. Their answers show which brands a model already knows, have no sources and carry the **No web search** label.

| Assistant | Model |
| --- | --- |
| Claude | Claude Haiku 5.5 |
| Grok | Grok 4.20 Non-Reasoning |
| Kimi | Kimi K2 |
| GLM | GLM 5.3 Flash |
| DeepSeek | DeepSeek V4 Flash |

## Retired models

Individual model versions such as GPT-5.6 Sol, Claude Opus, Grok 4.7 or Kimi K3 and coding agents such as Claude Code and Codex are no longer offered. Organizations created from November 8, 2026 start on the assistants above. On November 12, 2026 projects of older organizations moved to the matching assistant, so GPT models and Codex became ChatGPT, Gemini models became Gemini, every Claude model became Claude and Grok, Kimi, GLM and DeepSeek models moved to the versions above. For anything else, contact [hello@usenotra.com](mailto:hello@usenotra.com).

## Model limits

Each assistant multiplies the answers a scan uses, so more assistants use more of your AI answer quota.
