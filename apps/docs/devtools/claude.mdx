## Setup

<Steps>
  <Step title="Open Notra in the Claude directory">
    Open [claude.ai/directory/notra](https://claude.ai/directory/notra) and add the connector.
  </Step>

  <Step title="Sign in to Notra">
    Claude sends you to Notra to sign in, where you pick the organization you want to use and an access level of Read only, Write only or Full access.
  </Step>

  <Step title="Start using Notra in Claude">
    Claude stores the session and refreshes it in the background, so you only sign in once. Ask Claude about your AI visibility or ask it to draft content, and it calls the Notra tools for you.
  </Step>
</Steps>

Claude Code connects to the same server with one command:

```bash
claude mcp add --transport http notra https://mcp.usenotra.com/mcp
```

## What you can do

The connector has the same tools as the [MCP server](/devtools/mcp), which covers GEO, AEO and content. Here are a few prompts to start with:

- "Run a GEO scan for our tracked prompts and tell me where we dropped since last week."
- "Which competitors show up in AI answers for prompts where we don't?"
- "Find our biggest content gaps and draft a blog post for the first one in our brand voice."
- "How much traffic did AI crawlers and agents send to our docs this month?"

Claude saves each draft as a post in Notra, where you review and publish it from the dashboard.

<Warning>
  Some tools use credits or can't be undone, such as running scans, approving briefs and deleting data, so ask Claude to show you what it plans to do and confirm before it runs them.
</Warning>

## Notes

- The access level you pick when you sign in limits what Claude can do, so pick Read only if you only want Claude to report on your data.
- You can disconnect Notra from your Claude connector settings at any time, and you sign in again the next time you connect it.
